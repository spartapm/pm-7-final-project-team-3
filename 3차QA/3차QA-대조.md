## 0. 웹브라우저 · Mac 전체화면 프레임 잘림

QA: Mac Chrome 전체화면(16:9 / 21:9 / 16:10)에서 폰 프레임 안 콘텐츠가 너무 커서 배너·노란 누수 문구가 잘리고 말줄임됨. 프레임은 화면 높이에 맞춰 비례 축소하되, **안쪽 앱은 좁힌 창과 같은 390 모바일 비율**로 두고 세로만 스크롤. 스크롤바 숨김. 탭바는 프레임 하단 고정.

- **반영.** 데스크톱 `.phone`은 **390×844 고정**. 프레임만 `--phone-scale` + `transform: scale`로 창 높이에 맞춤. 안쪽 레이아웃·글자·배너는 같이 줄어들지 않음.
- 좁은 창에서 보이던 비율을 전체화면에도 그대로 씀. 세로가 모자라면 프레임 안에서 스크롤.
- `.scroll` 스크롤바 숨김 (`scrollbar-width: none` + webkit). 탭바는 셸 하단 고정.
- 파일: `components/ui.tsx` (`PhoneShell`), `app/globals.css`.

## 2. 로그인&회원가입 · 소셜 로그인

QA: 카카오·구글 활성화. 키는 드라이브 Docs.

- **반영 (조건).** OAuth 붙임. 카카오 콘솔은 설정 완료 기준으로 동작. 구글도 Redirect URI가 콘솔에 있어야 함.
- 시작: `/api/auth/kakao`, `/api/auth/google`
- 콜백: `/api/auth/kakao/callback`, `/api/auth/google/callback` → 세션 쿠키 → `/auth/callback` → `loginSocial`
- 로그인·회원가입 소셜 버튼이 위 API로 감 (`app/login/page.tsx`, `app/signup/page.tsx`).
- 등록할 Redirect URI:
  - `http://localhost:3003/api/auth/kakao/callback`
  - `https://myteum.vercel.app/api/auth/kakao/callback`
  - `http://localhost:3003/api/auth/google/callback`
  - `https://myteum.vercel.app/api/auth/google/callback`
- 배포본에서 실패하면 콘솔 Redirect URI 네 줄만 보면 됨. 키 값은 이 문서에 적지 않음.

  - `officialUrl` 없거나 실패 → 화면 유지 + 토스트
  - `brandColor` 없으면 `#3182f6`
- 375 시안의 모든 px(카드 13.4, 배지 59.5×22, 로고 겹침 148×88 등)를 픽셀 단위로 맞추진 않음. **구조·카피·토스트·뒤로가기** 우선.

### 9-4. 혜택 상세 뒤로가기

QA: `<`가 혜택 메인으로 고정되어 점검 결과를 다시 돌려야 함. `<`는 **직전 페이지**. 「메인으로 돌아가기」만 혜택 메인.

- **반영.** `<` = `router.back()`. 점검을 보고 들어왔으면 점검으로 돌아감.

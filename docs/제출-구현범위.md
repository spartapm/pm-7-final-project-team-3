# 틈(TEUM) 구현 범위 — 3조

기준: 피그마 [상세 기능명세 `1:228`](https://www.figma.com/design/G5i65LGv2ljKhvm8xN2cGU?node-id=1-228) + PRD In-scope  
배포: https://myteum.vercel.app  
데모: `demo@email.com` / `Demo1234!@` (신규 가입은 0건 홈)

이 제품은 **네이티브 앱이 아니라 웹 애플리케이션**입니다. 피그마 번호 항목의 화면·카피·상태는 웹으로 옮겼지만, OS 권한 시트·시스템 푸시·마이데이터처럼 웹에서 불가능하거나 1차 범위 밖인 기능은 구현하지 않았습니다. 그 구분은 아래 미구현에 따로 적습니다.

번호 항목마다 했고/부분/안 함은 [`docs/SPEC-INVENTORY.md`](./SPEC-INVENTORY.md) 에 모아 두었습니다. (`SP-AU-SignUp-01` … `SP-HM-Dashbd-01` …)

피그마 텍스트량이 많고 화면이 넓어서, **빠진 디테일이나 버그는 이번 제출에서 전부 닫았다고 보지 않습니다.** 일정 안에 전수 QA를 돌려 드리지 못했습니다. 배포본을 직접 만져 보시고 피드백 주시면, 그다음 라운드에서 맞추겠습니다.

## 구현한 것

### 01. 인증

- 로그인: 이메일·비밀번호 검증, 포커스 힌트, 종료 화살표 + 종료 확인 모달, 슬로건 로고
- 카카오·구글 소셜 로그인 (OAuth 콜백 후 가입/로그인)
- 회원가입: 비밀번호 확인, 전체동의, 만 14세 / 이용약관 / 개인정보 / 마케팅 + 자세히, 가입 후 로그인
- 약관 상세 4종 (TRI:ON · 틈)
- 가입 완료: 조아틈끼, 「로그인 하러 가기」 (9/8에 홈 로고 버튼 삭제)
- 비밀번호 찾기 → 6칸 인증코드(재전송 1분) → 새 비밀번호 → 완료. 화면·카피는 명세대로. 코드는 웹이라 실제 메일 발송 없이 `123456` (아래 미구현)

### 02. 홈·구독

- 첫 진입 알림 사전안내 팝업 (알림틈끼, 수신 동의/거부, 토스트)
- 홈: 알림 뱃지 9+, 슬라이드 배너 4장 3초, 주간 캘린더, 이번 달 구독비, 새는 구독 카피, MY 결제일, FAB +↔X
- 알림 사이드시트: 확인 / 모두 읽음
- 콜드 홈: 0원, 「아직 등록된 구독이 없어요」, 「예정된 결제가 없어요」
- 내 구독 목록: 요약 카드, 카테고리 칩, 정렬(결제일/금액/최신/상태), empty
- 구독 상세: 상태 드롭다운, 결합 문구, 결제수단, 삭제 확인(놀란틈끼)
- 구독 등록/수정: 필수 *, 서비스 자동완성, **첫 결제일 소형 캘린더(오늘 이전 비활성)**, 무료체험·기간, 결제수단 별칭, 알림 스위치(기본 OFF), 작성 중단 팝업
- 카탈로그 금액과 다르면 금액 필드 하단 `⚠️ {이름} 요금제와 달라요, 확인해주세요`
- 저장 완료 화면

계정·구독·일정·알림은 Supabase에 동기화됩니다. 데모 로그인은 피그마와 같은 샘플 구독이 채워집니다.

### 03. 캘린더·일상

- 월 캘린더: 구독/일상/전체 필터, 월 이동, 날짜 도트, 선택일 목록
- 공유: 지원 브라우저는 공유 시트, 아니면 텍스트 복사
- FAB: 구독 / 일상 × 이미지 / 음성 / 직접 입력
- 일상 등록/수정: 일정 이름 *, 일시 *, 하루 종일(기본 OFF), 알림 5종(기본 30분 전), 메모 50자
- 소형 캘린더를 먼저 고르고, 하루 종일이 아니면 TimePicker. 종료가 시작보다 이르면 빨간 테두리 + 「종료 시간은 시작 시간보다 늦어야 해요」
- 자정이 넘으면 종료일을 다음날로 넘김
- 일정 상세·삭제(복구 불가 카피)·저장 완료

### 이미지·음성 추가 (ADD)

- 이미지: 「추가 할 이미지를 올려주세요」, 최대 3장 PNG/JPG, 분석하기(1장 이상), 스캔 대기/실패, 닫으면 분석 결과로 안 넘어감
- 음성: 말씀해주세요 → 듣기(중단, 59초·백그라운드면 중단) → 저장(다시 말하기) → Gemini 분석. 종료 확인(궁금틈끼). 대기/실패 카피
- 추출 결과: 구독/일정 목록, 확인 필요, 직접 입력(둠칫틈끼), 일괄 저장, 카드 → 확인 폼
- 결과 이탈: 딤을 눌러도 안 닫힘. 계속 확인하기 / 나가기. 수정 없이 뒤로 가면 바로 이전 화면
- 확인 폼: 추출값 자동입력, 저장 전에는 내 목록에 안 들어감. 저장 없이 결과로 돌아가면 수정 전 값으로 돌아감
- Gemini 3.6. 결제일이 문자열로 와도 숫자로 읽고, 일정은 올해 기준으로 날짜를 채움. 분석이 멈추면 실패 화면

### 04. 혜택·AI 점검

- 혜택 홈: 카테고리, empty 「빈틈이 없어요!」, 카드틈끼, 점검받기
- 혜택 상세: 공식 서비스로 이동
- AI 점검: 대기(로딩틈끼·닫기) → 새는 구독 수/절약액, 구독 목록, 결합 상품 카드. 실패 시 우는틈끼 + 다시 시도 / 혜택 홈
- 점검은 **등록된 구독 + 공개 요금제 기준 예상치**. 자동 해지·변경은 하지 않음

### 06. 마이

- 마이 홈(셀카틈끼), 알림 설정(결제/가격/캘린더/마케팅, 즉시 반영)
- 로그아웃 확인
- 탈퇴: 안내, 사유 6종, 기타 입력, 완료 시트. 탈퇴 강조색 #FF0008

### 07. 빈 상태·상태 변형 · 웹 프레임

- 전역 실패 `/error`, 세션 만료 `/session`
- PC(넓은 화면): 390×844 폰 프레임, 배경, 슬로건 로고, 틈끼. 모바일에선 프레임 없이 화면만

### 스타일

- Noto Sans KR, 본문/버튼 390 폭, 모서리·딤드 시트·1차 블루 계열
- 공식 틈끼(조아/놀란/궁금/로딩/우는/셀카/마이크/둠칫 등)
- 피그마 모든 프레임을 픽셀 단위로 복제한 것은 아님. 레이아웃·카피·상태·인터랙션을 웹에 맞게 옮김. iOS 휠 TimePicker·네이티브 시트는 웹 소형 캘린더/스크롤 피커로 대체

## 구현하지 않은 것

웹이라서 안 하거나, 명세/PRD에서 1차 제외이거나, 일정 안에 네이티브 수준까지 못 맞춘 항목입니다.

### 웹이라서 불가능하거나 다르게 동작

- **OS 푸시 알림**: 결제 예정은 앱 안 알림 목록으로만 생성. 잠금화면·시스템 배너는 없음
- **마이크/사진 앨범 OS 권한 팝업**: 브라우저는 자체 권한 창을 씀. 이미지 등록 전 OS 권한 화면은 웹 예외로 없음. 파일은 파일 선택기
- **설정 앱으로 이동**: 음성 권한에서 「설정으로 이동」은 브라우저 주소창 권한을 안내
- **백그라운드 녹음 유지**: 탭이 숨겨지면 듣기를 끊음 (명세의 백그라운드 중단과 같음). 앱이 꺼진 채 녹음은 불가
- **Web Speech API**: Chrome 등에서만 안정적. Safari/일부 환경은 인식이 약하거나 없음
- **실제 이메일 인증코드**: 비밀번호 찾기 화면은 있으나 메일은 안 감. 코드는 `123456`
- **설치형 앱 / 위젯 / 홈 화면 아이콘**: 웹만

### 명세·PRD에서 1차 제외 (버튼·카피만 두거나 아예 없음)

- 마이데이터, 카드번호 입력, 실제 해지 대행
- 외부 캘린더 .ics import/export
- 다른 앱 구독 자동 해지·변경

### 명세 문구는 있으나 웹/일정 기준으로 덜 맞춘 것

- 이미지·음성에서 **서로 다른 값이 복수로 인식**된 필드 경고: 지금은 추출값 1개 + 카탈로그 금액 불일치만
- AI 점검의 결합 상품 카드는 **고정 추천**. 사용자 구독마다 Gemini가 새로 짜지 않음
- 캘린더 공유는 시스템 캘린더 연동이 아니라 텍스트 공유/복사
- 피그마 시안과 자간·아이콘 픽셀·일부 hex(`#3182F6` vs `#2576F2`)는 다를 수 있음
- 실제 영수증 다장 스캔·실제 마이크 발화는 환경에 따라 Gemini/브라우저가 실패할 수 있음 (실패 화면은 있음)
